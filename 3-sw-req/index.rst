===================================================
Tiger Detection System - SW Requirements
===================================================

This project contains the software-level requirements for the Tiger Detection
System. These requirements are **solution-agnostic** — they define what the
software must do without prescribing a specific implementation technology
(e.g. AUTOSAR, bare-metal, Linux).

SW requirements trace upward to system requirements (``1-sys-req``) via the
``:satisfies:`` link. The SW design (``5-sw-design``) traces downward from
these requirements.
