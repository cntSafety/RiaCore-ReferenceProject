RiaCore Demo Project

This is the demo project for RiaCore ([github.com/cntSafety/RiaCore](https://github.com/cntSafety/RiaCore)).

## Getting started

1. Install RiaCore following the instructions in its repository.
2. Add the importers to load this project's data 
3. Do the safety analysis.

Alternatively, the ready-made ria project in the `5-safety` folder can be opened with RiaCore directly.
